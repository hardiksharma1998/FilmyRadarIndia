# FilmyRadarIndia

Modern responsive movie & OTT discovery homepage.

## Included
- Dark cinematic responsive UI
- Home hero section
- Latest Movies
- OTT Releases
- Web Series
- Upcoming Releases
- Trending Now sidebar
- Latest News & Articles
- Search/filter
- Mobile navigation
- Newsletter form interaction
- Social CTA
- SEO-ready title and meta description

## Run
Open `index.html` directly in a browser, or deploy the folder to Vercel/Netlify/GitHub Pages.
